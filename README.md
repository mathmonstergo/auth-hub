# auth-hub

自用的多平台凭据中枢：把各平台的 Cookie / 登录态集中存在一处，供本机其他程序取用。主要是给自己接入 [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) 做采集时用。

支持的平台：

- 哔哩哔哩：扫码登录
- 小红书 / 抖音 / 微博 / 百度贴吧 / 知乎：粘贴 Cookie

界面预览：<https://mathmonstergo.github.io/auth-hub/>
